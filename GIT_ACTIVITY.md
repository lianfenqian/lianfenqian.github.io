# Optional Git Extension (5 minutes)

1. Run `git init`.
2. Run `git status`.
3. Commit the starter files:
   `git add README_STUDENT.md R data run_pipeline.R`
   `git commit -m "Add broken housing analysis pipeline"`
4. Repair the pipeline.
5. Inspect changes with `git diff`.
6. Commit the fix:
   `git add R run_pipeline.R`
   `git commit -m "Repair pipeline paths and validate inputs"`

Do not commit generated files unless your instructor requests them. Do not commit secrets or restricted data.
